# PersonalWebsite

## Overview
A personal portfolio website showcasing my background, technical skills, professional experience, academic projects, and contact information. The website also features an interactive chatbot that allows visitors to learn more about me in a conversational way.

## Features
- Responsive portfolio website
- Interactive chatbot
- Professional experience timeline
- Project showcase with GitHub links
- Technical skills overview
- Contact information

## Technologies
- Angular
- TypeScript
- HTML5
- CSS3
- Bootstrap
